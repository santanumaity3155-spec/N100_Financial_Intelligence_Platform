## 6. CORRELATION METHODOLOGY

A 10-KPI Pearson correlation matrix was computed for latest company records:
$$r_{X, Y} = \frac{\sum (X_i - \bar{X})(Y_i - \bar{Y})}{\sqrt{\sum (X_i - \bar{X})^2 \sum (Y_i - \bar{Y})^2}}$$
Selected KPIs: `roe`, `roce`, `roa`, `net_profit_margin`, `operating_margin`, `ebit_margin`, `debt_to_equity`, `interest_coverage`, `asset_turnover`, `inventory_turnover`.

Heatmap specifications:
- Dimensions: 10x10 matrix
- Symmetric ($r_{i, j} = r_{j, i}$)
- Diagonal elements $= 1.00$
- Values strictly bounded in $[-1.00, +1.00]$
- Visualized with Seaborn `coolwarm` palette, numerical annotations (`fmt=".2f"`), clear axis labels, and saved to `reports/correlation_heatmap.png`.

---

## 7. OUTLIER DETECTION METHODOLOGY

Z-scores were calculated within each `broad_sector`:
$$Z_{i, f} = \frac{X_{i, f} - \mu_{\text{sector}, f}}{\sigma_{\text{sector}, f}}$$
where $\sigma_{\text{sector}, f}$ uses sample standard deviation ($\text{ddof}=1$).
- **Threshold**: Outlier flagged if $|Z_{i, f}| > 3.0$.
- **Zero-Std / 1-Sample Safety**: If $\sigma_{\text{sector}} = 0$ or sample size $\le 1$, $Z$ is assigned `NaN`, no division-by-zero occurs, and outlier flag is `False`.
- **Output**: 5 outliers detected across Financial Services and Energy & Power sectors, saved to `output/outlier_report.csv`.
