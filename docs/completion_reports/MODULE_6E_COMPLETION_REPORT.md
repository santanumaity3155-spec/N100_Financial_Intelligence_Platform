## 5. Screener Filters
The `GET /api/v1/screener` endpoint supports seven query parameters:
- `min_roe` (ROE >= threshold)
- `max_de` (D/E <= threshold)
- `min_fcf` (FCF >= threshold)
- `sector` (exact or partial sector match)
- `min_rev_cagr_5yr` (5Y Revenue CAGR >= threshold)
- `min_pat_cagr_5yr` (5Y PAT CAGR >= threshold)
- `max_pe` (P/E <= threshold)

**Semantics & Validation**:
- Missing/NULL financial values are safely handled without coercion to zero.
- Invalid non-numeric query parameters return `HTTP 400 Bad Request`.
- Valid query parameters that match zero companies return an empty list `[]` with `HTTP 200 OK`.

## 6. Sector Analytics
- `GET /api/v1/sectors`: Aggregates all authoritative sectors in the database dynamically. Computes company count, median ROE, median P/E, and median D/E per sector.
- `GET /api/v1/sectors/{sector}/companies`: Case-insensitive matching against broad sectors and sub-sectors. Returns 404 for unknown sectors.

---

## 7. Peer Endpoints
- `GET /api/v1/peers/{group_name}`: Returns percentile ranks for all 10 core metrics for every company in the peer group.
- 10 Peer Metrics: `roe`, `roce`, `net_profit_margin`, `debt_to_equity`, `free_cash_flow`, `revenue_cagr_5yr`, `pat_cagr_5yr`, `eps_cagr_5yr`, `interest_coverage`, `asset_turnover`.
- Returns `HTTP 404 Not Found` for unknown peer groups.

---

## 8. Peer Comparison (Radar Data)
- `GET /api/v1/companies/{ticker}/peers/compare`: Returns 8 radar axis metrics comparing:
  1. Requested company metric values
  2. Peer group average metric values
  3. Benchmark company metric values
- 8 Radar Axes: `roe`, `roce`, `net_profit_margin`, `debt_to_equity`, `free_cash_flow`, `revenue_cagr_5yr`, `pat_cagr_5yr`, `composite_quality_score`.
- Returns `HTTP 404` for invalid tickers and a controlled non-crashing response if a company has no assigned peer group.

---

## 9. Market-Cap / Valuation Endpoint
- `GET /api/v1/market-cap/{ticker}`: Returns chronological historical valuation multiples from 2019 to 2024.
- Metrics exposed: `pe_ratio`, `pb_ratio`, `ev_ebitda`, `dividend_yield`, `market_cap`, `enterprise_value`.
- Returns `HTTP 404` for unknown tickers.

## 10. Portfolio Statistics
- `GET /api/v1/portfolio/stats`: Returns statistical distribution for core KPIs across the universe.
- Includes `P10`, `P25`, `P50`, `P75`, `P90`, `Mean`, `Std`, and sample count.
